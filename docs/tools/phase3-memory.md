# Phase 3 개인 기억 Tool

- `memory.remember.v1` (R1): 사용자가 명시적으로 요청한 별칭·선호·메모를 승인 후 저장하거나 같은 종류·키로 갱신한다.
- `memory.list.v1` (R1): 승인 후 만료되지 않은 기억을 검색해 최대 50개 모델에 전달한다.
- `memory.forget.v1` (R1): `memory.list`가 반환한 ID의 기억 하나를 승인 후 삭제한다.

기억은 `general`, `personal`, `sensitive` 민감도를 가지며 선택적으로 1~3650일 뒤 만료할 수 있다. 기억 값은 진단 및 감사 요약에 저장하지 않는다. API 키, 비밀번호, 인증 토큰은 기억 대상이 아니며 Windows Credential Manager 같은 전용 비밀 저장소를 사용한다.

사용자는 메인 화면의 **기억 관리**에서 모델 호출 없이 활성·만료된 모든 기억을 검색·추가·수정·삭제할 수 있다. 만료된 항목은 모델과 별칭 해석에 사용하지 않고 화면에 `만료됨`으로 표시한다. JSON 내보내기는 기억 원문이 암호화되지 않은 파일에 기록된다는 경고와 명시적 확인 뒤 수행한다.

경로·앱 이름 등 제한된 Windows Tool 대상 인자는 `$alias:<키>` 또는 `$preference:<키>`로 저장 값을 참조할 수 있다. Desktop이 승인 preview 전에 이를 해석하고 승인된 값을 실행까지 고정하므로 값은 모델로 반환되지 않는다.
