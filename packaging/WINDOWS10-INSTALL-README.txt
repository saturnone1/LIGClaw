LIGClaw Windows 10 설치 방법
==============================

1. 이 압축파일을 먼저 모두 풉니다.
2. Install-LIGClaw.cmd를 더블클릭합니다.
3. Windows가 관리자 권한을 요청하면 "예"를 누릅니다.
4. 설치 완료 메시지가 나오면 시작 메뉴에서 LIGClaw를 실행합니다.

지원 환경: 64비트 Windows 10 버전 1809 이상

관리자 권한은 LIGClaw 설치용 공개 인증서를 이 컴퓨터의
"신뢰할 수 있는 사용자" 저장소에 등록할 때 한 번 필요합니다.
개인 인증서나 개인키는 이 배포본에 포함되어 있지 않습니다.
